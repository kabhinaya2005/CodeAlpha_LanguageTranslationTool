# CodeAlpha Language Translation Tool

A simple web-based Language Translation Application developed as part of the CodeAlpha Artificial Intelligence Internship.

## Features

- Simple and user-friendly interface
- Enter text for translation
- Select the target language
- Translate text using a translation API
- Supports multiple languages
- Responsive web design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Translation API

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling and layout
- `script.js` – Translation functionality

## How to Use

1. Open the application.
2. Enter the text you want to translate.
3. Select the target language.
4. Click the Translate button.
5. The translated text will be displayed.
